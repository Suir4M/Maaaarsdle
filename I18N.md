# Marsdle i18n

## Ajouter une langue

1. Créer `game/locales/<code>.json` en copiant la structure de `fr.json`.
2. Ajouter le code de langue dans `SUPPORTED` dans `game/i18n.js`.
3. Ajouter les traductions des clés communes et les noms propres dans `names`.
4. Tester l'accueil et chaque univers sur ordinateur et mobile.

## API

```js
MarsdleI18n.t("common.newGame");
MarsdleI18n.t("common.guessedIn", { count: 3 });
MarsdleI18n.getLanguage();
MarsdleI18n.setLanguage("en");
MarsdleI18n.translateName("Severus Rogue");
```

Les nouvelles fonctionnalités doivent utiliser des clés stables et explicites (`common.newGame`) plutôt que d'écrire directement des phrases dans le code.

## Compatibilité temporaire

Le projet contient encore des moteurs historiques qui écrivent leurs textes directement en français. Le pont de compatibilité dans `i18n.js` traduit ces textes existants. Il est volontairement isolé et documenté pour pouvoir être retiré progressivement lorsque chaque moteur utilisera `MarsdleI18n.t()` et des données localisées.

Les personnages doivent conserver un identifiant stable indépendant de leur nom affiché. Les alias de recherche doivent être définis par langue afin que les traductions ne modifient jamais la logique de comparaison.
